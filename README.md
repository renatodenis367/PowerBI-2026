📊 Power BI Data Analytics Project – Data Technician Bootcamp

📌 Overview

This repository contains the Power BI portion of the Week 2 workbook completed during the Data Technician Bootcamp by LeepTalent. The project follows the Microsoft PL-300T00: Design and Manage Analytics Solutions Using Power BI lab path, covering the complete analytics workflow — from data ingestion and transformation to semantic modelling, DAX calculations, and interactive report design.

The skills practised are directly applicable to retail and sales data analysis, where clean data models, accurate measures, and compelling visual stories are essential for decision‑making.

🛠️ Skills Demonstrated

Data Transformation & Cleaning (Power Query)
Lab 1 – Get data in Power BI: Connected to and imported data from multiple sources.

Lab 2 – Clean, transform, and load data: Used Power Query to:

Remove duplicates and handle missing values.

Change data types and rename columns.

Split, merge, and pivot/unpivot columns.

Filter rows and shape tables for analysis.

Load a clean, analysis‑ready model into Power BI.

Semantic Modelling

Lab 3 – Configure a semantic model:

Created relationships between tables (star schema).

Set cardinality and cross‑filter directions.

Configured table visibility and formatting.

Optimised the model for performance and usability.

DAX Calculations

Lab 4 – Create DAX calculations in semantic models:

Built calculated columns (e.g., profit margin, year‑over‑year flags).

Created measures using SUM, AVERAGE, CALCULATE, FILTER, and time‑intelligence functions.

Used DIVIDE for safe division and IF/SWITCH for conditional logic.

Developed reusable KPIs for sales, revenue, and growth.

Interactive Reports & Visualizations

Lab 8 – Design Power BI reports:

Built a multi‑page report with a consistent layout and theme.

Added slicers (e.g., date, region, product category) for user‑driven filtering.

Used cross‑filtering and drill‑through for interactive exploration.

Applied bookmarks and buttons for navigation.

Chart Type	Usage in Project
Bar / Column Chart	Sales by product, revenue by region, top‑N customers
Line Chart	Sales trends over time, year‑over‑year growth
Pie / Donut Chart	Category share of total sales
Map	Sales by country/region (geographic visual)
Card / KPI	Total revenue, average order value, profit margin
Table / Matrix	Detailed sales breakdown by product and period
Data Storytelling
Structured reports to answer business questions: What sold? Where? When? How much profit?

Used titles, annotations, and colour consistently to guide the viewer.

Combined KPIs with trends and geographic views for a complete sales narrative.

Retail & Sales Context: The same workflow — clean data → model relationships → write DAX measures → build interactive visuals — is exactly how retail analysts report on sales performance, inventory, and customer behaviour.
